Выбери характер BeeCode

Четыре направления — один интерфейс. Открой каждый (клик по карточке), попробуй: понажимай кнопки, введи текст и Enter, открой меню модели и выбери другую — акцент поменяется под бренд. Потом назови номер.

01 · ТЁМНЫЙ НЕОН

Neon Glass

Глубокий тёмный фон, стеклянные панели, неоновые свечения от акцента модели. Стекло + градиенты. Самый «дорогой» вид.
02 · СВЕТЛЫЙ ПАСТЕЛЬ

Aurora Paper

Мягкие акварельные градиенты, белые карточки, воздух. Тёплый уютный минимализм с цветными акцентами.
03 · РЕТРО-ТЕРМИНАЛ

Terminal CRT

Моноширинный шрифт, сканлайны, фосфорный акцент. Для тех, кто любит хакерский стиль — как старый добрый CRT.
04 · РЕЗКИЙ СТУДИЙНЫЙ

Brutal Studio

Жёсткие чёрные рамки, смещённые тени, крупная типографика. Без скруглений, максимально характерно.
